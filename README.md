# Ink & Equity

Preview build for Ink & Equity (Lucknow). A single-page site in one self-contained HTML file; English with a full Hindi toggle.

- `index.html` is the built page; open it in a browser. Fonts load from Google Fonts.
- Source: `meta.json`, `style.css`, `body.html`, and `js/NN-*.js` (concatenated in filename order by `build.py`).
- Status: **draft, not reviewed by an advocate.** Real facts only; anything only people can supply is an empty, labelled frame.
- Contact forms send nothing. No grievance contact or email address is set yet.
- Drafted with AI assistance (Claude); to be disclosed on the live site.
